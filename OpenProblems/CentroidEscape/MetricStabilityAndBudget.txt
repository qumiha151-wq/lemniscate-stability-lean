3. Flow comparison and the clamp caveat

For two approximate trajectories f,g in the actual tube, let h=f-g and
 r=(f'-g')-(F(f)-F(g)). If metricNorm(r)<=delta, Cauchy-Schwarz yields
 E(h)' <=2K E(h)+2delta sqrt(E(h)).
Apply scalar one-sided Gronwall to sqrt(E+epsilon^2), then let epsilon->0:
 metricNorm(h(t)) <= d0 exp(Kt)+(delta/K)(exp(Kt)-1).
This retains K rather than replacing it with the Jacobian operator norm.

The coordinatewise-clamped field need not satisfy this same one-sided bound.
It is used solely for global existence. For an inner-tube reference, a first
exit argument proves nearby clipped solutions remain in the true tube:
 if metricNorm(b-a) exp(KT)<1/2000, they cannot first attain metric distance
 1/2000 from the reference. Prior to a first hit both solve the original
field, so the preceding comparison contradicts the hit. This supplies
the actual original-field parameter neighborhood at the improved scale.
