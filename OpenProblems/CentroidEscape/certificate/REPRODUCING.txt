REPRODUCE THE VALIDATION
Use Python 3.12+ with python-flint 0.9.0 (the successful run used the Python
version recorded in validated_certificate.json). For an isolated environment:

  python -m venv .venv
  .venv\Scripts\python -m pip install python-flint==0.9.0
  .venv\Scripts\python validate_certificate.py --center certificate_center.json --workers 3 --output rerun_certificate.json

On macOS/Linux use .venv/bin/python instead. The optional work/pydeps path
in the scripts is a convenience for the original workspace; an ordinary
installed python-flint package also works. No other third-party Python
package is required by the final validator. Three workers are optional;
--workers 1 runs sequentially. Expected runtime is several minutes.

The validator reads certificate_center.json and never changes it. It performs
7 independent order-160 Taylor integrations, each with 750 steps at 180
Arb decimal digits. It records failure rather than a passing certificate
if any required inequality fails. Use a different output filename when
rerunning so the original evidence remains available.
