Current direct-stage format and native five-path preflight
Each stage is proved independently, using a typed validity proof for final
assembly. Synchronization points every10 stages prevent deferred elaboration
from retaining excessive memory; the same numerical statements then compile
under the controlled4GB cap. Raising the cap was not the accepted fix.

The direct first-step format measured51,154 source bytes and1,163,008 olean
bytes,34.315s/peak resident2.601GB. A two-step import and strict audit used
about1.689GB resident, with audit loop under1s. This format's full compiled
step is about1.2MB; counting only the data and individual lemmas understates
its size. A whole3750-step extrapolation is still not a measured full build.
The concrete first-ten-step block is being used to measure cloud cost before
scaling. The repository is public, and its existing ubuntu-latest workflow
uses standard hosted runners; actual job logs are the performance evidence.
