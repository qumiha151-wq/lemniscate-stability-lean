WHAT IS PROVED

be a real reference state and M(t) a real invertible reference matrix.
The differential data are actual HasDerivWithinAt statements:
  X' = sigma*f(X) + rx,
  M' = (sigma*Df(X))*M + Z,
where |sigma|<=1, ||rx||<=delta, ||Z||<=rho,
||M||<=K and ||inverse M||<=I. The state and matrix residuals are
independent and may use different Taylor orders.

For w=inverse M*(actual-X), exact differentiation derives
  w' = inverse M*(sigma*(f(actual)-f(X)-Df(X)*(actual-X)) - rx - Z*w).
The original-field derivative is used only at points already proved to
be in outerTube. The actual cubic field has the exact remainder identity
  f(y)-f(x)-Df(x)*(y-x)
    = bilinear((2/3)*x+(1/3)*y, y-x, y-x),
which gives a quadratic bound 2*||y-x||^2 in the convex outerTube.

If ||w||<R and reference X has coordinate margin K*R, the actual state
is in outerTube, so the true transformed derivative is bounded by
  C = I*(2*K^2*R^2 + rho*R + delta).
A compact first-threshold argument uses this estimate only BEFORE the
first threshold. The strict segment budget then excludes the threshold,
including its terminal point. Global clipped-flow existence and
continuity supply the trajectory without assuming tube confinement.

The matrix transition uses the new inverse bound. A finite recurrence
accumulates both additive state jumps and multiplicative matrix jumps.
