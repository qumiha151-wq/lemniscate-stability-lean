The dedicated core schema cannot stand in for numerical-shard certification.
It binds complete raw archive SHA/size, actual successful pack/restore/private
1704/331 plus Arctan evidence, exact helpers and the three upstream artifact
origins. Actual publication requires an explicit pinned Actions invocation,
actual Git HEAD and committed publisher blob at earlier code commit P. The
later workflow commit Q is recorded independently; no commit hashes itself.

The mutation sequence checks absent tag/draft/release, creates a new exact
lightweight tag and draft, uploads one canonical asset, verifies draft metadata
and a complete byte redownload, then publishes and repeats complete download,
metadata and tag checks. No overwrite, delete, tag move, automatic retry or
automatic cleanup is implemented. Upload is a bounded stream with explicit
Content-Length; authenticated redirects are disabled. Signed binary redirects
are constrained and carry no API token. Journal intents precede mutations.

new directory entries. Windows tests explicitly did not exercise directory

is made; the workflow must upload journal and evidence even after failure.
