# The remaining tests for the primitive one-turn rotating expander

The two concrete grids have verified inverse bounds at every index from zero to 4000 inclusive. This holds as a single quantified theorem for each sign, including the two terminal points. Each proved inverse is attached to the same integer state used in the corresponding grid. [Positive arm](../../../SolitonClassification/Rotating/ResetAllInversesPlus.lean) · [Negative arm](../../../SolitonClassification/Rotating/ResetAllInversesMinus.lean)

For each of the 8,000 polynomial cells, the remaining tests are its signed differential-equation defect, bounds on its state and matrix entries, and agreement of its first and last values with the two adjacent integer grid points. These tests imply the existence of a smooth unit-speed rotating and expanding curve with signed turning minus one, curvature of both signs and length strictly between 60 and 62. Lean also proves that this is its **shortest positive position period**, allowing arbitrary real proposed periods. [Finite cell conditions](../../../SolitonClassification/Rotating/ResetOnlyCells.lean) · [Geometric conclusion](../../../SolitonClassification/Rotating/ResetPrimitiveCells.lean)

The period assertion uses only the actual immersion and its signed turn. For any real shift, a continuous periodic scalar function takes equal values at some pair of points with that separation: its difference after translation has opposite weak signs at a maximum and a minimum. Apply this observation to the tangent angle plus its linear drift. A position period makes the two tangents equal there, forcing the proposed period to be an integer multiple of the length. [Exact period lattice](../../../SolitonClassification/Rotating/IntegerTurningPeriod.lean)

To regenerate the inputs in a checkout with this project's Lean toolchain and Python with python-flint, run `python replay_complete.py nodes` from this directory to reconstruct and check the two grids. The command `python replay_complete.py full` additionally generates the 500 cell batches, assembles both arms, and requests the final theorem. The script checks the canonical line-ending-independent SHA-256 of each generated input before staging it. Existing sources must agree. Each proof term for the finite arithmetic is evaluated in the Lean kernel.
